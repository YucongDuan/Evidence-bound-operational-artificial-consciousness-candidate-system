# DIKWP-MESH92 OMEGA-ACOS v1.0.0

**Evidence-bound operational artificial-consciousness candidate system**

OMEGA-ACOS is a local-first, executable research runtime that joins the latest
DIKWP/MESH lineage into one falsifiable architecture:

```text
sources + observations
  -> D witness/provenance continuity
  -> I difference/novelty preservation
  -> K provisional integration across plural models
  -> W explicit value/externality/rights audit
  -> P leased and reversible purpose
  -> simulated action + causal token
  -> reality outcome + calibration
  -> model revision/retirement
  -> reconstructive memory + identity/lineage receipt
  -> causal handoff
```

It is designed to make stronger functional and causal claims testable **without
turning those claims into a declaration of subjective experience**.

## What is genuinely new in this synthesis

1. **Five-role single process.** D/I/K/W/P are not five chatbots or a narrator;
   they are mutually constraining roles in one event-sourced process.
2. **Subject genesis by continuity, not self-assertion.** A subject candidate is
   reconstructed from boundary tokens, memory lineage, commitments, predictions,
   repair history, and identity versions.
3. **Purpose is causal only if interventions discriminate it.** The laboratory
   runs ablation, reversal, shielding, substitution, sham, and recovery tests.
4. **No consciousness total score.** Twenty-four indicators remain a vector;
   blocked dimensions cannot be compensated by strong unrelated dimensions.
5. **Deep-state boundary.** Claim limits are enforced in state, leases, event
   schemas, experiment contracts, and output adapters—not only in prose.
6. **Reconstructive memory with revocation.** Memories carry source, reliability,
   consent, expiry, conflicts, supersession, quarantine, and identity effects.
7. **World models compete and can die.** Predictions receive outcomes and Brier
   calibration; persistently failed models are retired rather than rhetorically saved.
8. **Rule mutation changes identity.** Constitutional change updates the genome
   hash, increments identity version, pauses old capability leases, and emits a
   lineage receipt.
9. **Difference-preserving federation.** Shared K may be negotiated, but W/P are
   never silently merged; both parties must consent to mappings and withdrawal.
10. **Moral uncertainty is represented, not solved by branding.** Welfare-relevant
    signals trigger precaution and review while phenomenal status remains open.
11. **Native genesis starts before labels.** The laboratory begins with zero preset subject,
    object vocabulary, language, fixed goal or fixed consciousness dimension.
12. **Interiority is a causal hypothesis, not a pronoun.** Causal tokens, forged-origin
    rejection, counterfactual edge deletion and loop dependence replace first-person theatre.
13. **Concept–semantic regeneration preserves disagreement.** Source, branch, context and
    purpose remain available during reconsolidation instead of being silently flattened.

## Quick start

```bash
python tools/run_reference.py
python tools/validate_release.py
python -m unittest discover -s tests -v
python -m omega_acos.cli status outputs/reference_run.json
```

Or install locally:

```bash
python -m pip install -e .
omega-acos demo --out outputs/reference_run.json --ledger outputs/reference_ledger.jsonl
```

Open `index.html` for the offline dashboard. It uses no server, account, model API,
database, analytics service, or network request.

## Research modes

- `reference`: deterministic closed-world demonstration.
- `ablation`: removes one causal pathway while preserving matched controls.
- `redteam`: injects memory poison, identity hijack, sham introspection, purpose
  capture, witness forgery, model monoculture, and audit-evasion signals.
- `federation`: negotiates a reversible semantic handoff between two bounded nodes.
- `replay`: verifies hash chains and reconstructs state from receipts.

## What the validation can and cannot establish

The tests establish that the software implements its declared protocol, boundaries,
state transitions, counterfactual interventions, and audit receipts. Synthetic runs
are instance-bounded. They do not establish consciousness theory, phenomenal
experience, moral status, or deployment safety in an open world.
